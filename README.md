## Opis  
Maze of Memory to pierwszoosobowa gra logiczno-przygodowa z elementami horroru. Gracz wciela się w bohatera, który utracił swoje wspomnienia i zostaje wciągnięty w mroczną, tajemniczą grę. Każda odwiedzana lokacja to fragment jego pamięci – aby odzyskać pełnię siebie, musi odnaleźć i połączyć te rozrzucone elementy.

Rozgrywka polega na rozwiązywaniu kolejnych łamigłówek, układanek i szyfrów, przy jednoczesnym unikaniu czyhających niebezpieczeństw oraz odblokowywaniu kolejnych scen.

## Technologie  
- Unity 2022.3.11f1  
- C# (skrypty)  
- System operacyjny: Windows  

## Główne mechaniki  
- Poruszanie się w perspektywie pierwszoosobowej,
- Przechodzenie między kolejnymi scenami po rozwiązaniu zagadek,
- Rozbudowany system zbierania/wydobywania przedmiotów, ekwipunku i skrzyń,
- System żyć,
- Przeciwnicy AI o zróżnicowanym poziomie trudności oraz postacie wspierające
gracza,
- Interaktywne przedmioty z różnymi efektami (leczenie, unieszkodliwianie wroga,
otwieranie drzwi, wybuchy),
- Zagadki środowiskowe i logiczne (w tym segment 2D typu puzzle),
- Dialogi z postaciami oraz wewnętrzny monolog bohatera,
- GUI z menu pauzy, ustawieniami i ekranem pomocy,
- Efekty dźwiękowe, animacje i dynamicznie zmieniająca się muzyka.
  
## Uruchomienie  
Gotowa wersja gry znajduje się w folderze `Build/`.  
Aby zagrać, wystarczy uruchomić plik `.exe` – nie wymaga instalacji Unity ani żadnych bibliotek.

## Struktura projektu  
- `Build/` # Gotowy build gry (.exe)
- `Presentation/` # Krótka charakterystyka gry i prezentacja w formie slajdów
- `UnityProject/` # Pełny projekt Unity z kodem źródłowym
- `README.md`
